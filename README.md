# LeadForge AI — Production-Grade Lead Generation Platform

> An AI-powered SaaS platform for web design and AI automation agencies. Find local business leads, score them with AI, generate custom website previews, and create personalized cold outreach — all in under 5 minutes.

---

## Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 15 (App Router, Turbopack) |
| Language | TypeScript (strict) |
| Styling | Tailwind CSS + Framer Motion |
| Database | Supabase (PostgreSQL) + Prisma ORM |
| AI | Claude API (Anthropic) + OpenAI GPT-4o |
| Scraping | Google Maps Places API + SerpAPI + Cheerio |
| Auth | Supabase Auth |
| UI | Shadcn UI + Radix UI |
| Charts | Recharts |
| Deployment | Vercel |

---

## Features

- **AI Lead Scraper** — Google Maps, Yelp, BBB scraping with 40+ data points per lead
- **Reachability Scoring** — AI scores every lead 1–100 (HOT / LIKELY / MEDIUM / LOW)
- **Tech Detection** — Detects SSL, mobile-friendliness, chatbots, booking, AI tools, CMS, frameworks
- **AI Website Generator** — Full niche-specific website HTML generated by Claude
- **Cold Email Generator** — 5-email sequences with subject lines and SMS variants
- **Call Script Generator** — Full scripts + objection handling + voicemail + ROI pitch
- **Website Audit Engine** — Tech profiling + AI summary + opportunities + revenue impact
- **CRM Pipeline** — Kanban board with deal tracking, notes, and follow-ups
- **Campaigns** — Multi-step outreach campaign manager with analytics
- **Landing Page** — Full SaaS marketing site with animations

## Quick Start

### 1. Clone & Install

```bash
git clone https://github.com/yourrepo/leadforge-ai.git
cd leadforge-ai
npm install
```

### 2. Environment Variables

```bash
cp .env.example .env.local
```

Fill in all values in `.env.local` (see `.env.example` for all required keys).

**Required API Keys:**
- `NEXT_PUBLIC_SUPABASE_URL` + `NEXT_PUBLIC_SUPABASE_ANON_KEY` — [supabase.com](https://supabase.com)
- `SUPABASE_SERVICE_ROLE_KEY` — Project Settings → API in Supabase
- `DATABASE_URL` + `DIRECT_URL` — Supabase Project Settings → Database → Connection String
- `ANTHROPIC_API_KEY` — [console.anthropic.com](https://console.anthropic.com)
- `OPENAI_API_KEY` — [platform.openai.com](https://platform.openai.com)
- `GOOGLE_MAPS_API_KEY` — Google Cloud Console (enable Places API)
- `SERPAPI_KEY` — [serpapi.com](https://serpapi.com)

### 3. Database Setup

```bash
# Generate Prisma client
npm run db:generate

# Push schema to Supabase
npm run db:push

# (Optional) Open Prisma Studio
npm run db:studio
```

### 4. Supabase Auth Setup

In your Supabase project:
1. Go to **Authentication → Providers** → Enable **Email** and optionally **Google/GitHub**
2. Set **Site URL** to `http://localhost:3000` (dev) or your production URL
3. Add redirect URL: `https://yourapp.com/auth/callback`

### 5. Run Dev Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment (Vercel)

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

**Environment variables** must be set in Vercel project settings (copy from `.env.local`).

**Important Vercel config:**
- Set Node.js version to 20.x
- Enable Edge Runtime is NOT required (we use Node runtime for Prisma)
- Add `PUPPETEER_SKIP_CHROMIUM_DOWNLOAD=true` if Puppeteer causes build issues

For production scraping on Vercel (serverless), replace Puppeteer with [Browserless](https://browserless.io) or [Playwright on Vercel](https://vercel.com/templates/playwright).

## API Reference

### `POST /api/scrape`
Start a lead scraping job.

```json
{
  "niche": "HVAC contractors",
  "location": "Dallas TX",
  "radius": 25,
  "minReviews": 5,
  "requireWebsite": false,
  "maxResults": 50
}
```

### `GET /api/scrape?jobId=xxx`
Poll scrape job status and results.

### `POST /api/audit`
Run a full website audit for a lead.
```json
{ "leadId": "clxxx..." }
```

### `POST /api/generate/website`
Generate an AI website for a lead.
```json
{ "leadId": "clxxx...", "regenerate": false }
```

### `POST /api/generate/email`
Generate cold email sequence.
```json
{ "leadId": "clxxx...", "senderName": "Alex", "senderAgency": "YourAgency" }
```

### `POST /api/generate/script`
Generate cold call script.
```json
{ "leadId": "clxxx...", "senderName": "Alex" }
```

## Customization

### Add New Niches
Edit `NICHE_THEMES` in `src/lib/ai/website-generator.ts` to add custom design themes for any niche.

### Adjust Scoring Weights
Edit `calculateReachabilityScore` in `src/lib/scraper/scoring.ts` to change factor weights.

### Custom AI Prompts
All prompts are in the respective `src/lib/ai/*.ts` files — edit them freely.
